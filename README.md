## RambonL

Developer based in Germany, focused on Java, Python and Linux-based infrastructure.
Main areas: server-side Minecraft modding (Fabric), automation tooling and self-hosted services.

### Projects

| Project | Description |
|---|---|
| [deathcounter](https://github.com/RambonL/deathcounter) | Server-side Fabric mod that records player deaths with full history and coordinates. Compatible with vanilla clients. |
| [mangaupdates-anilist-import](https://github.com/RambonL/mangaupdates-anilist-import) | Imports a MangaUpdates reading list into AniList via the GraphQL API |
| [cutomizespotify](https://github.com/RambonL/cutomizespotify) | Stream Deck buttons that hide or like the playing Spotify track, using the desktop client's DevTools Protocol |
| [downloadController](https://github.com/RambonL/downloadController) | Python tool for managing downloads |

### Behind the scenes

Most of my work lives in private repositories, including:

- **Self-hosting & infrastructure:** containerized services, a centralized logging stack, automated backups and a custom service dashboard
- **Game servers:** Minecraft server tooling, mod management and a shared Java utility library
- **Web:** browser games and a JavaScript backend for a web project
- **Game development:** a simulation prototype in Godot
- **Smart home:** C# control software for home automation
- **Desktop environment:** Wayland compositor configuration, custom QML shell and a Lua-based Neovim setup
